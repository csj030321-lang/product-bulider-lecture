# 🎰 황금손 로또 6/45 번호 추첨기 (Golden Lotto)

다크 모드와 화이트(라이트) 모드를 지원하며, 실감나는 3D 애니메이션과 Web Audio 사운드 효과를 제공하는 로또 6/45 행운 번호 추첨 웹 애플리케이션입니다.

## ✨ 주요 기능

1. **다크 모드 & 화이트 모드 완벽 지원**
   - 상단 헤더의 전용 테마 스위처로 원클릭 즉시 전환 (🌙 다크 모드 / ☀️ 화이트 모드)
   - `localStorage`를 통해 사용자의 테마 설정을 영구 기억
   - OS 시스템 테마(`prefers-color-scheme`) 자동 감지 및 고대비 가독성 최적화

2. **실시간 생방송 라이브 추첨**
   - 3D 로또 추첨기 회전 및 1~6번 공 + 보너스 볼 순차적 등장
   - 공식 6/45 색상 적용 (노랑, 파랑, 빨강, 회색, 초록, 보너스 보라)
   - Web Audio API 기반 구슬 굴림 & 축하 팡파르 효과음
   - Canvas Confetti 축하 파티클 효과

3. **5세트 일괄 생성 (A, B, C, D, E)**
   - 로또 복권 용지 1장(5천원권) 분량 원클릭 생성
   - 개별 세트 및 5세트 전체 클립보드 원클릭 복사

4. **고정수 & 제외수 커스텀 필터링**
   - 고정수(반드시 포함할 번호): 최대 5개
   - 제외수(절대 포함하지 않을 번호): 최대 39개
   - 직관적인 1~45 번호판 인터랙티브 선택기

5. **추첨 기록 관리 (LocalStorage)**
   - 이전 추첨 이력 로컬 브라우저 자동 보관
   - 기록 개별 복사 및 전체 초기화

6. **번호 통계 및 조합 가이드**
   - 현재 추첨 번호의 총합, 홀짝 비율, 고저 비율 실시간 계산
   - 번호대별 출현 통계 꿀팁 제공

7. **Formspree 연동 제휴 및 광고 문의 폼**
   - 엔드포인트: `https://formspree.io/f/xdeooqza`
   - 비즈니스 제휴, 광고 문의, 기능 피드백 비동기 AJAX 접수
